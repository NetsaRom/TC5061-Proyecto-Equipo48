# Documentación de modelos de Machine Learning

En esta sección se documentarán los modelos de Machine Learning desarrollados para el proyecto MiBici MLOps. Cada documento describirá el objetivo del modelo, los datos utilizados, la preparación de características, los algoritmos implementados, el proceso de entrenamiento y las métricas de evaluación correspondientes.

## Modelos desarrollados

### 1. Regresión

Modelos orientados a predecir valores numéricos relacionados con la demanda de viajes de MiBici, como la cantidad de viajes por estación y hora.

Consulta la [documentación del modelo de regresión](modelo_regresion.md).

### 2. Clasificación

Modelos orientados a asignar categorías o clases a las observaciones, de acuerdo con el objetivo definido para el proyecto.

Consulta la [documentación del modelo de clasificación](modelo_clasificacion.md).

### 3. Clustering

Modelos de aprendizaje no supervisado orientados a identificar grupos de estaciones u observaciones con características similares.

Consulta la [documentación del modelo de clustering](modelo_clustering.md).

## Objetivo de la documentación

Centralizar la documentación técnica de los modelos del proyecto, facilitar la comparación de resultados y promover la reproducibilidad y trazabilidad de los experimentos mediante MLflow.

Los documentos se actualizarán conforme avance el desarrollo y la evaluación de cada modelo.
